# YouTube transcript research

Find the videos that matter on a topic, read their transcripts, and answer with claims tied to timestamped links.

**Disclosure:** the actors this skill runs are built and sold by Arcadium Data, the author of this skill. You pay Apify per video delivered (see Cost). No affiliate codes are used.

## Example prompts

- "What do the top YouTube reviews of the Framework Laptop 13 complain about? Cite timestamps."
- "Summarise the last 20 videos of @kurzgesagt and list the topics."
- "Get the transcript of https://www.youtube.com/watch?v=dQw4w9WgXcQ."

Out of scope:

- YouTube comments (no public Arcadium actor for them yet).
- Downloading video or audio files.

## Prerequisites

- Apify account and `APIFY_TOKEN`, or `apify login`. Apify CLI (`npm i -g apify-cli`) or the Apify MCP server (`https://mcp.apify.com`).

## Workflow

### 1. Find videos (skip if the user gave links)

<!-- input: youtube-videos -->
```json
{
  "searchQueries": ["framework laptop 13 review"],
  "maxResults": 30,
  "listingOnly": true,
  "dateFilter": "year"
}
```

    apify actors call arcadium/youtube-videos --input-file search.json --user-agent arcadium-skills/youtube-transcript-research --json 2>/dev/null
    apify datasets get-items DATASET_ID --format json --user-agent arcadium-skills/youtube-transcript-research 2>/dev/null > videos.json

(`DATASET_ID` is `.defaultDatasetId` from the call output.) Rows carry `videoId`, `url`, `title`, `channelName`, `viewCount` (rounded in fast mode), `durationSeconds`, `publishDate` (approximate when `publishDateIsApprox` is true) and `position` (search rank). For a channel, put its URL (`https://www.youtube.com/@handle`) in `urls` instead of `searchQueries`.

Pick 10-20 videos: drop Shorts and videos under 3 minutes for in-depth topics, prefer a spread of channels, and tell the user which ones you chose and why.

### 2. Pull the transcripts

<!-- input: youtube-transcripts -->
```json
{
  "urls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"],
  "languages": ["en"],
  "includeSegments": true
}
```

    apify actors call arcadium/youtube-transcripts --input-file transcripts.json --user-agent arcadium-skills/youtube-transcript-research --json 2>/dev/null

Put all chosen video URLs in `urls` (one run, one start fee). A channel or playlist URL also works, with `maxVideosPerSource` and `publishedAfter` (`YYYY-MM-DD`) to limit it.

Read from `rowType: "transcript"` rows: `transcript` (full text), `segments` (`start`, `duration` in seconds, `text`), `language`, `isAutoGenerated`, `languageMatched`, `availableLanguages`, plus `title`, `channelName`, `publishDate`, `viewCount`, `wordCount`. For non-English videos set `translateTo: "en"`.

### 3. Write the research note

For each video: title, channel, date, views, and 3-6 key claims. For every claim give a timestamp link `<url>&t=<start>s`, using the `start` of the segment where the claim is made (rounded down). Then a cross-video section: points most videos agree on, points of disagreement, and claims only one creator makes. Quote transcript text exactly; mark auto-generated captions (`isAutoGenerated: true`) because names and numbers in them can be misheard.

## MCP instead of the CLI

With the Apify MCP server connected, call `arcadium/youtube-videos` and `arcadium/youtube-transcripts` with the same inputs.

## Troubleshooting

- A free row with `rowType: "error"` and a `code` means no transcript (no captions, private, age-restricted or missing). Check `availableLanguages` on delivered rows to request another language.
- `languageMatched: false`: none of the requested languages exists; the original spoken language was returned.
