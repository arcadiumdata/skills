# YouTube transcript

Transcripts of YouTube videos, fetched in the Apify cloud and returned as one JSON row per video.

**Disclosure:** the actor this skill runs is built and sold by Arcadium Data, the author of this skill. You pay Apify per transcript delivered (see Cost). No affiliate codes are used.

## When to use it

- The user gives one or more YouTube links or video IDs and wants the text, a summary, quotes or timestamps.
- The user wants the transcripts of a channel or playlist (newest first, optional date range).
- A local tool fails: `youtube-transcript-api` raises `RequestBlocked` or `IpBlocked` (YouTube blocks most cloud-provider IPs, as that library's README explains), or `yt-dlp` asks to sign in to confirm you are not a bot. If a local tool works for the user, it is fine to keep using it; this skill is for when it does not.

Out of scope:

- Videos without captions: the actor does not download or transcribe audio.
- Age-restricted and members-only videos (they need a signed-in account; the actor never logs in).
- Comments, video or audio downloads. For a broad topic search across many videos, use the `youtube-transcript-research` skill.

## Prerequisites

- Apify account and `APIFY_TOKEN`, or `apify login`. Apify CLI (`npm i -g apify-cli`) or the Apify MCP server (`https://mcp.apify.com`).

## Workflow

### 1. Build the input

<!-- input: youtube-transcripts -->
```json
{
  "urls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"],
  "languages": ["en"],
  "includeSegments": true
}
```

- `urls`: video links, `youtu.be` links, Shorts links, bare video IDs (`dQw4w9WgXcQ`), channel URLs (`https://www.youtube.com/@kurzgesagt`) or playlist URLs. Put every video in one run (one start fee).
- Channels and playlists: add `maxVideosPerSource` (for example 20) and optionally `publishedAfter` / `publishedBefore` (`YYYY-MM-DD`).
- `languages`: in order of preference; `en` also matches `en-US` and `en-GB`. If none exists, the original spoken language is returned and `languageMatched` is `false`.
- `captionType`: `any` (default, creator captions first), `manual` or `auto`.
- `subtitleFormat`: `srt` or `vtt` adds a ready subtitle file to each row.
- `includeSegments: false` when only the plain text is needed (smaller output).

From youtube-transcript-api: `YouTubeTranscriptApi().fetch(video_id, languages=["de", "en"])` maps to `{"urls": [video_id], "languages": ["de", "en"]}`. The segments use the same `text`, `start` and `duration` fields.

### 2. Run it

    apify actors call arcadium/youtube-transcripts --input-file transcripts.json --user-agent arcadium-skills/youtube-transcript --json 2>/dev/null
    apify datasets get-items DATASET_ID --format json --user-agent arcadium-skills/youtube-transcript 2>/dev/null > transcripts.out.json

(`DATASET_ID` is `.defaultDatasetId` from the call output.) Without the CLI, one HTTP call returns the rows: `POST https://api.apify.com/v2/acts/arcadium~youtube-transcripts/run-sync-get-dataset-items` with header `Authorization: Bearer $APIFY_TOKEN` and the input as the JSON body. In Python: `ApifyClient(token).actor("arcadium/youtube-transcripts").call(run_input=...)`, then iterate `client.dataset(run.default_dataset_id).iterate_items()` (apify-client 3.x).

### 3. Read the rows

Filter on `rowType` first.

- `transcript` rows: `videoId`, `url`, `title`, `channelName`, `publishDate`, `durationSeconds`, `viewCount`, `transcript` (full text), `segments` (`start`, `duration` in seconds, `text`), `wordCount`, `language`, `isAutoGenerated`, `languageMatched`, `availableLanguages`, and `srt` / `vtt` when asked.
- `error` rows (free): `code` and `message`, plus the `input` they are about.

For a summary or quotes, cite timestamps as `<url>&t=<start>s` using the `start` of the segment (rounded down). Quote the text exactly and say when captions are auto-generated (`isAutoGenerated: true`): they have no punctuation and names or numbers may be misheard. For long transcripts, use `wordCount` to decide whether to summarise in chunks.

## Troubleshooting

- `no_match`: the video has no captions (or none of the requested `captionType`). Nothing to retry.
- `not_found`: private, removed or unknown video or channel.
- `unavailable`: age-restricted, members-only, not yet published, or a temporary error; retry later only for the temporary case.
- `blocked`: YouTube still refused after all retries; run again later.
- `languageMatched: false`: the requested language does not exist; check `availableLanguages`. `translateTo` returns a native track in that language only when the video has one, because YouTube currently refuses its machine translation to anonymous clients (`translationStatus: "unavailable"`); translate the text yourself in that case.
